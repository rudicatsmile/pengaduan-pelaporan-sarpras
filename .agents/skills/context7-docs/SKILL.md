# Context7 Documentation Skill (Laravel & Flutter)

This project uses **Laravel** for the backend and **Flutter** for the mobile app. 
Whenever you need to look up documentation, API references, or best practices for either framework, you MUST use the Context7 CLI tool to fetch the most up-to-date information before writing code.

## How to use

Run the following command using your `run_command` tool:

For **Laravel**:
```bash
npx ctx7@latest docs laravel "<your search query>"
```

For **Flutter**:
```bash
npx ctx7@latest docs flutter "<your search query>"
```

## Guidelines
- Always wrap your query in quotes.
- Keep your search query concise and specific (e.g., `"Eloquent mass assignment"`, `"ImagePicker camera compress"`).
- Use this skill proactively when you are unsure about a framework feature or API.
